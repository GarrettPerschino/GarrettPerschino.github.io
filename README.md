# Perschino Labs GitHub Pages site

This folder is ready to upload to a public GitHub repository named:

```text
GarrettPerschino.github.io
```

## Upload through GitHub

1. Create a public repository named `GarrettPerschino.github.io`.
2. Open the repository.
3. Select **Add file → Upload files**.
4. Extract the downloaded ZIP on your computer.
5. Drag every extracted file and folder into the GitHub upload area.
6. Confirm that `index.html`, `404.html`, `assets/`, and `speed-lab/` appear at the repository root.
7. Commit the files to the `main` branch.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
10. Select **Save**.
11. Wait for the Pages deployment to finish under **Actions**.
12. Test these URLs in an incognito window:

```text
https://GarrettPerschino.github.io/
https://GarrettPerschino.github.io/speed-lab/
https://GarrettPerschino.github.io/speed-lab/privacy.html
https://GarrettPerschino.github.io/speed-lab/support.html
```

## Add another product

Create another product folder at the repository root, such as:

```text
another-app/
├── index.html
├── privacy.html
└── support.html
```

Copy the Speed Lab page structure, then replace all product-specific text and policy details. Add the product to the root `index.html` product section.

Speed Lab privacy

This policy explains what Speed Lab handles, why it handles it, and where the information stays.

Effective date: August 6, 2026 · Publisher: Perschino Labs

Overview

Speed Lab is a Chrome extension that provides precise playback-speed controls for YouTube videos.

Speed Lab processes playback information locally so it can show controls, apply a selected speed, and remember user preferences.

Information handled locally

Speed Lab stores these settings in Chrome:

  • Default playback speeds
  • User-created speed presets
  • Keyboard shortcut preferences
  • Playback-speed memory preferences
  • Player-control visibility preferences
  • Current-tab playback-speed memory

Speed Lab also processes the current YouTube page type, the active HTML video element, and requested playback-rate changes. This processing occurs locally in the browser.

How information is used

Speed Lab uses this information only to:

  • Display playback-speed controls
  • Apply the playback rate selected by the user
  • Remember user-selected settings
  • Restore playback preferences during YouTube navigation
  • Provide separate behavior for standard videos and Shorts

Data not collected

Speed Lab does not collect or transmit:

  • Names, email addresses, or identification numbers
  • Google or YouTube account information
  • Passwords or authentication information
  • Video titles or channel names
  • YouTube watch history or general browsing history
  • Personal communications
  • Financial, health, or location information
  • Analytics, advertising, or tracking identifiers
  • Keystroke logs or records of shortcut use

Data transmission

No user data is sent to Perschino Labs.

Speed Lab does not use external servers, analytics providers, advertising systems, or telemetry services.

Storage and retention

Persistent preferences are stored with chrome.storage.local. They remain until the user resets Speed Lab or removes the extension.

Current-tab speed memory is stored with chrome.storage.session. Session information expires with the relevant browser session.

Permissions

  • Storage: saves playback settings and current-tab speed memory.
  • Scripting: reconnects packaged extension code to YouTube tabs that were already open or need to reconnect after an update.
  • YouTube host access: locates the active video, displays the speed control, and applies the selected playback rate on youtube.com and m.youtube.com.

Sharing and selling

Perschino Labs does not sell, rent, share, or transfer user data.

Information is not used for advertising, profiling, creditworthiness, lending, or any purpose unrelated to playback-speed control.

Remote code

Speed Lab does not download or execute remote JavaScript or WebAssembly. All executable code is included in the extension package distributed through the Chrome Web Store.

User controls and deletion

Users can delete stored Speed Lab information by:

  • Opening Speed Lab settings and selecting Reset settings
  • Removing Speed Lab from Chrome

Chrome Web Store Limited Use

Speed Lab uses information only to provide or improve the product's disclosed playback-speed functionality. Its information handling complies with the Chrome Web Store User Data Policy, including Limited Use requirements.

This website

This Perschino Labs site contains no analytics, advertising, tracking scripts, forms, cookies created by site code, or external executable code.

Changes to this policy

This policy may be updated if Speed Lab's functionality or information practices change. The effective date at the top of the page will be updated when material changes are published.

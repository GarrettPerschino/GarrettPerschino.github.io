Install and start

  1. Install Speed Lab from the Chrome Web Store.
  2. Open a standard YouTube video or a YouTube Short.
  3. Refresh YouTube tabs that were already open before installation.
  4. Select the Speed Lab toolbar icon or the speed chip inside the player controls.
  5. Choose a preset, use the plus and minus controls, or enter an exact speed in the popup.

Default keyboard controls

S

Decrease speed

D

Increase speed

R

Reset to 1×

G

Return to the previous speed

Hold B

Temporary 2× playback

V

Show or hide the player control

Shortcuts do not run while typing in search, comments, forms, or other editable fields.

Troubleshooting

The player control does not appear

Open an active YouTube video, refresh the tab, and confirm that Player control is enabled in the Speed Lab popup or settings page. The control does not appear on the YouTube homepage when no video is active.

The extension popup says no video is active

Start a YouTube video, then open the Speed Lab popup again. If the tab was open before installation or before an update, refresh it once.

The selected speed resets

Confirm that Remember speed is set to Current tab or All videos. Refresh the YouTube tab after updating the extension.

A requested speed is not supported

Chrome or the media source can limit playback speed. Speed Lab applies the nearest supported value and prevents repeated technical errors at the detected limit.

Keyboard shortcuts do not work

Click outside search, comments, forms, and editable fields. Check Speed Lab's advanced settings to confirm the in-page shortcut assignments. Chrome-level shortcuts can also be reviewed at chrome://extensions/shortcuts.

Shorts use a different speed

Speed Lab keeps a separate default for YouTube Shorts so a high long-form playback speed does not automatically carry into every Short. Change the Shorts default in Advanced settings.

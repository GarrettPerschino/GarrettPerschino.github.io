Install and start

  1. Install Speed Lab from the Chrome Web Store.
  2. Open a YouTube video or Short.
  3. Refresh tabs that were open before installation.
  4. Open the Speed Lab popup or select the player control.
  5. Select a preset or enter an exact speed.

Default keyboard controls

S

Decrease speed

D

Increase speed

R

Reset to 1×

G

Return to the previous speed

Hold B

Temporary 2× playback

V

Show or hide the player control

Shortcuts do not run while typing in search, comments, forms, or other editable fields.

Troubleshooting

The player control does not appear

Open an active YouTube video. Refresh the tab. Open the Speed Lab popup. Confirm that Player control is enabled. The control does not appear when no video is active.

The Speed Lab popup says no video is active

Start a YouTube video. Open the Speed Lab popup again. Refresh the tab if it was open before installation or an update.

The selected speed resets

Open Advanced settings. Set Remember speed to Current tab or All videos. Refresh the YouTube tab after an update.

A requested speed is not supported

Chrome or the video source can limit playback speed. Speed Lab uses the nearest supported speed.

Keyboard shortcuts do not work

Click outside search, comments, forms, and editable fields. Open Advanced settings. Check each in-page shortcut. Review Chrome shortcuts at chrome://extensions/shortcuts.

Shorts use a different speed

Speed Lab stores a separate default for Shorts. Change the Shorts default in Advanced settings.

Contact support

Send an email to perschinolabs@gmail.com.

Include:

  • Your Chrome version
  • The Speed Lab version
  • Whether the issue occurs on a standard video, Short, playlist, or fullscreen player
  • Clear steps that reproduce the issue
  • A screenshot when it helps explain the problem
